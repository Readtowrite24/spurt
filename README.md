# Sportclub De Spurt

Dit is de oude website van Sportclub De Spurt, de klant van de Dag 2-opdracht van Discover IT.
Download de bestanden met **Code → Download ZIP** om eraan te werken.
Om je werk te publiceren maak je een **Fork**, upload je daarin wat je veranderde, en zet je onder *Settings → Pages* GitHub Pages aan vanaf de branch `main`.
Je site staat dan op `https://<gebruikersnaam>.github.io/spurt/`.
